Manifest / Order Cycle Tool

Procurement Order Generator PRO Edition

Turn sellout history and branch stock into ready-to-send supplier order sheets. Enhanced with Supply Chain restraints (Lead Time, MOQ, Packing Constraints) and active state preservation.

1

Set the global run parameters

These apply to every supplier in this run.

Advanced Supply Chain Formula:
Target Cover Window = Stock Cover Days + Supplier Lead Time
Raw Required Order = ceil(avg daily sellout × Target Cover Window) − stock on hand
Final Order = Multiples of Case Pack Size (Adjusted upward if below item MOQ)
2

Add suppliers & upload files

Configure vendor-specific supply restraints, upload inventory balances and sales logs.

3

Generate order sheets

Builds one spreadsheet workbook equipped with audit layers and downloads it.

Reads .xlsx sheets completely local client-side. Operations are preserved in local persistence memory.
